# 유니티 프로젝트 규칙

Unity 프로젝트를 여럿이 함께 쓸 때만 생기는 문제들에 대한 규칙입니다. 코드 규칙과 달리 **어겼을 때 바로 다른 사람의 작업이 깨지는** 항목들입니다.

---

## 1. 에디터 설정

작업을 시작하기 전에 한 번 확인합니다. `Edit > Project Settings > Editor`

| 항목 | 값 | 이유 |
| --- | --- | --- |
| `Version Control > Mode` | `Visible Meta Files` | `.meta` 파일이 보여야 Git이 함께 기록합니다 |
| `Asset Serialization > Mode` | `Force Text` | 씬과 프리팹이 텍스트로 저장되어 변경 내용을 볼 수 있습니다 |

이 설정이 다르면 다른 사람과 파일이 어긋납니다. <mark>설정을 임의로 바꾸지 않습니다.</mark>

## 2. Unity 버전

`ProjectSpec.md` 에 적힌 버전만 씁니다. Unity Hub가 다른 버전으로 열라고 권해도 열지 않습니다.

<mark>상위 버전으로 한 번 열면 프로젝트가 변환되고, 되돌릴 수 없습니다.</mark> 그 상태로 커밋되면 전원이 버전을 올려야 합니다.

## 3. 씬

- 다른 사람의 씬은 열어서 확인만 하기
- 본인 기능을 시험할 때는 `Assets/Scenes/Test/` 아래에 본인 이름으로 테스트 씬을 만듭니다. 테스트 씬은 빌드 설정에 넣지 않습니다.
- 씬에 무언가를 배치해야 하는데 내 씬이 아니라면, **프리팹으로 만들어 두고 소유자에게 배치를 요청**합니다.

## 4. 프리팹

- 되도록 프리팹으로 만들어 배치 프리팹 안의 수정은 씬 파일을 건드리지 않으므로 충돌 감소
- 프리팹을 고칠 때는 씬에 놓인 인스턴스가 아니라 **프리팹 자체를 열어서** 고칩니다.
- 남이 만든 프리팹을 고쳐야 하면 먼저 말합니다.
- 프리팹 이름은 `FolderStructure.md` 의 규칙을 따릅니다.

## 5. `.meta` 파일

- `.meta` 는 에셋의 짝입니다. **항상 에셋과 함께 커밋합니다.** 한쪽만 올리면 다른 사람 쪽에서 연결이 끊어집니다.
- `.meta` 파일을 직접 열어서 고치지 않습니다.
- 에셋을 옮기거나 이름을 바꿀 때는 **Unity 에디터 안에서** 합니다. 탐색기에서 옮기면 `.meta` 가 따라가지 않아 연결이 끊어집니다.

## 6. 커밋에서 제외되는 것

`.gitignore` 가 처리하므로 신경 쓸 일은 많지 않지만, 아래는 알아 둡니다.

| 제외 대상 | 이유 |
| --- | --- |
| `Library/` | 엔진이 만드는 변환 캐시. `Assets` 와 설정만 있으면 다시 만들어집니다 |
| `Temp/`, `Logs/` | 에디터 실행 중의 임시 파일 |
| `UserSettings/` | 창 배치 등 개인 설정 |
| `Build/`, `Builds/` | 빌드 결과물. 소스에서 다시 만들 수 있습니다 |
| `*.csproj`, `*.sln` | 엔진이 자동으로 만들어 냅니다 |

<mark>빌드 결과물을 저장소에 올리지 않습니다.</mark> 용량이 크고, 커밋 이력이 빌드 파일로 뒤덮입니다. 발표용 빌드는 별도로 전달합니다.

## 7. 외부 에셋

- 에셋스토어나 외부에서 받은 것은 `Assets/Imports/` 아래에 넣습니다.
- **받기 전에 팀과 강사에게 확인합니다.** 패키지 하나가 프로젝트 설정을 바꾸는 경우가 있습니다.
- 받은 즉시 `Docs/AssetCredits.md` 에 출처와 라이선스를 적습니다.
- 외부 에셋의 파일 이름은 바꾸지 않습니다. 원본 그대로 둡니다.
- 쓰지 않게 된 에셋은 지웁니다. 남겨 두면 용량만 차지합니다.

### 파일 크기

GitHub은 한 파일이 **50MB를 넘으면 경고**하고 **100MB를 넘으면 push 자체를 막습니다.** 큰 모델이나 긴 음원이 여기 걸릴 수 있습니다. 받기 전에 크기를 봅니다.

## 8. 패키지

Package Manager에서 패키지를 추가·제거하면 `Packages/manifest.json` 이 바뀌고, 이것은 전원에게 영향을 줍니다. **혼자 결정하지 않고 팀에 먼저 말합니다.**

추가한 뒤에는 `[Chore]` 타입으로 따로 커밋해서 무엇이 들어왔는지 보이게 합니다.
